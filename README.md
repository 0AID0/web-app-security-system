# 🛡️ Web App Security System

**Интерактивная учебно-демонстрационная платформа по кибербезопасности.**

Каждый модуль системы — это рабочая демонстрация современного механизма защиты:
шифрование данных, аутентификация, работа с защищёнными БД, сетевые технологии
и мониторинг безопасности.

## ✨ Что умеет система

Платформа состоит из **шести тематических разделов**, каждый из которых содержит
интерактивные примеры с реальным кодом и рабочим интерфейсом.

### 🔐 Шифрование данных
- **AES-256** — симметричное блочное шифрование с длиной ключа 256 бит
- **RSA** — асимметричное шифрование с открытым ключом
- **ECC** — криптография на эллиптических кривых

### 🔑 Аутентификация
- **JWT (JSON Web Tokens)** — токены доступа на основе JSON
- **OAuth 2.0** — протокол авторизации без передачи пароля
- **MFA** — многофакторная аутентификация (SMS, приложение, биометрия)

### 🗄️ Базы данных
- **MongoDB с шифрованием** — документо-ориентированная БД с шифрованием на уровне поля
- **PostgreSQL с row-level security** — реляционная СУБД с контролем доступа на уровне строк
- **Redis с TLS** — хранилище ключ-значение с шифрованием трафика

### 🧰 Фреймворки и инструменты
- **Node.js** — серверная платформа с модулями безопасности (Helmet, CSRF-защита)
- **Express.js** — минималистичный веб-фреймворк с middleware для безопасности
- **OWASP ZAP** — инструмент тестирования безопасности веб-приложений

### 🌐 Сетевая безопасность
- **VPN** — защищённое соединение поверх ненадёжной сети
- **Firewall** — контроль входящего и исходящего трафика по правилам
- **IDS/IPS** — обнаружение и предотвращение вторжений

### 📊 Мониторинг и аудит
- Логирование событий безопасности
- Симуляция атак (Brute-force, доступ к `/admin`)
- Статистика угроз за 30 дней
- Ролевой доступ (RBAC): обычный пользователь, модератор, администратор

Система построена по принципу **модульности и масштабируемости**.

```
┌─────────────────────────────────────────────────┐
│                  Клиент (SPA)                   │

└──────────────────────┬──────────────────────────┘
                       │ HTTP / REST API
┌──────────────────────▼──────────────────────────┐
│              Сервер (Node.js + Express)         │
│  ┌──────────────┬──────────────┬─────────────┐  │
│  │ Крипто-модуль│  Auth-модуль │  API-модуль │  │
│  └──────┬───────┴──────┬───────┴──────┬──────┘  │
└─────────┼──────────────┼──────────────┼─────────┘
          │              │              │
     ┌────▼────┐    ┌────▼────┐    ┌────▼────┐
```

## 🚀 Как запустить

### Требования
- Node.js 18+
- Современный браузер (Chrome, Firefox, Edge)

### Способ 1. Скачать и открыть (самый простой)

1. Скачай репозиторий:
   - Нажми зелёную кнопку **Code** → **Download ZIP**.
   - Распакуй архив.
2. Открой файл **`index.html`** в браузере (двойной клик).
3. Готово — система работает. 🎉

### Способ 2. Через Live Server (для разработки)

1. Открой папку проекта в **VS Code**.
2. Установи расширение **Live Server**.
3. Правой кнопкой по `index.html` → **Open with Live Server**.
4. Сайт откроется по адресу `http://127.0.0.1:5500`.
