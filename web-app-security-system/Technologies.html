Шифрование данных

AES-256

Симметричный алгоритм блочного шифрования с длиной ключа 256 бит, обеспечивающий высокий уровень безопасности. Используется для защиты конфиденциальных данных как в хранилищах, так и при передаче.

RSA

Асимметричный криптографический алгоритм с открытым ключом, используемый для безопасной передачи данных. Особенно полезен для обмена ключами и цифровых подписей.

ECC (Elliptic Curve Cryptography)

Криптография на эллиптических кривых обеспечивает аналогичную безопасность RSA при значительно меньших размерах ключей, что делает её идеальной для мобильных устройств.

Аутентификация

JWT (JSON Web Tokens)

Открытый стандарт для создания токенов доступа, основанный на формате JSON. Обеспечивает безопасную передачу информации между сторонами в виде JSON-объекта.

OAuth 2.0

Протокол авторизации, позволяющий предоставлять доступ к защищенным ресурсам без передачи паролей. Широко используется для авторизации через социальные сети.

Многофакторная аутентификация (MFA)

Метод контроля доступа, при котором пользователю для получения доступа необходимо предъявить несколько доказательств аутентификации.

Базы данных

MongoDB с шифрованием

Документоориентированная NoSQL база данных с поддержкой шифрования на уровне поля. Обеспечивает безопасное хранение структурированных и неструктурированных данных.

PostgreSQL с row-level security

Реляционная СУБД с поддержкой безопасности на уровне строк, позволяющая точно контролировать доступ к данным для разных пользователей.

Redis с TLS

Хранилище ключ-значение с поддержкой шифрования трафика через TLS. Обеспечивает безопасное кэширование и работу с временными данными.

Фреймворки и инструменты

Node.js

Серверная платформа для выполнения JavaScript-кода с богатой экосистемой модулей безопасности, таких как Helmet для защиты HTTP-заголовков.

Express.js

Минималистичный веб-фреймворк для Node.js с поддержкой middleware для безопасности, включая защиту от CSRF, XSS и других атак.

OWASP ZAP

Инструмент для тестирования безопасности веб-приложений с открытым исходным кодом. Помогает выявлять уязвимости в приложениях.

Сетевая безопасность

VPN (Virtual Private Network)

Технология создания защищённого соединения поверх ненадёжной сети. Обеспечивает конфиденциальность и целостность передаваемых данных.

Firewall

Система сетевой безопасности, которая отслеживает и контролирует входящий и исходящий сетевой трафик на основе заранее установленных правил безопасности.

IDS/IPS

Системы обнаружения и предотвращения вторжений (Intrusion Detection/Prevention Systems) для мониторинга сетевой активности на предмет вредоносных действий.
