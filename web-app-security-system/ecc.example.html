ECC — криптографический алгоритм с открытым ключом, основанный на алгебраической структуре эллиптических кривых. Обеспечивает аналогичную безопасность RSA при значительно меньших размерах ключей, что делает её идеальной для мобильных устройств.

В этом демо используется библиотека elliptic для реализации ECC в браузере.

Управление ключами

Информация: Ключи сохраняются в localStorage вашего браузера и будут доступны при следующем посещении.
