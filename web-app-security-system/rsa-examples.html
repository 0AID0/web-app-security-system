RSA — криптографический алгоритм с открытым ключом, основанный на вычислительной сложности факторизации больших чисел. Используется для безопасной передачи данных, цифровых подписей и обмена ключами.

В этом демо используется библиотека JSEncrypt для реализации RSA в браузере.
