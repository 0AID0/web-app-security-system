На главную

Обзор инструмента

OWASP ZAP (Zed Attack Proxy) - это один из самых популярных в мире инструментов для тестирования безопасности веб-приложений с открытым исходным кодом, разрабатываемый под эгидой OWASP (Open Web Application Security Project).

Поиск уязвимостей

Автоматическое обнаружение уязвимостей, таких как SQL-инъекции, XSS, CSRF и другие.

Сканирование

Активное и пассивное сканирование веб-приложений для выявления проблем безопасности.

Интерфейсы

Доступен через графический интерфейс, командную строку и API для интеграции в CI/CD.

Установка OWASP ZAP

# Установка на Windows
1. Скачайте установщик с https://www.zaproxy.org/download/
2. Запустите установщик и следуйте инструкциям

# Установка на Linux (Debian/Ubuntu)
sudo apt update
sudo apt install zaproxy

# Установка на macOS с Homebrew
brew install --cask owasp-zap

# Запуск ZAP
zap.sh # Linux/macOS
Или через ярлык на рабочем столе в Windows

Демонстрация установки

Базовая конфигурация

# Настройка прокси в браузере
1. Откройте настройки сети браузера
2. Установите ручные настройки прокси:
  - Адрес: 127.0.0.1
  - Порт: 8080

# Настройка контекста в ZAP
1. Правой кнопкой на "Контексты" → Новый контекст
2. Укажите URL вашего приложения
3. Настройте область действия (Scope)

# Настройка аутентификации (если требуется)
1. В контексте перейдите на вкладку "Аутентификация"
2. Выберите тип аутентификации
3. Укажите параметры входа

Запуск в Docker

# Запуск ZAP в Docker
docker pull owasp/zap2docker-stable
docker run -u zap -p 8080:8080 -i owasp/zap2docker-stable zap.sh -daemon -port 8080 -host 0.0.0.0 -config api.disablekey=true

# Запуск автоматического сканирования
docker run -i owasp/zap2docker-stable zap-baseline.py -t https://example.com

# Запуск полного сканирования
docker run -i owasp/zap2docker-stable zap-full-scan.py -t https://example.com

# Запуск API сканирования
docker run -i owasp/zap2docker-stable zap-api-scan.py -t https://example.com/api.json -f openapi

Быстрое сканирование

# Запуск быстрого сканирования
1. Введите URL в поле "URL для атаки"
2. Нажмите кнопку "Быстрая атака"
3. Дождитесь завершения сканирования

# Из командной строки
zap-cli quick-scan --self-contained --start-options '-config api.disablekey=true' -s all -r report.html http://example.com

Демонстрация быстрого сканирования

Использование Spider

# Запуск Spider
1. Убедитесь, что URL добавлен в контекст
2. Правой кнопкой на URL → Атака → Spider
3. Настройте параметры (глубина, потоки и т.д.)
4. Нажмите "Запустить Spider"

# Из командной строки
zap-cli spider http://example.com

# Параметры Spider
--max-depth 5 # Максимальная глубина
--threads 10 # Количество потоков
--post-form # Анализ форм POST

Демонстрация Spider

Активное сканирование

# Запуск активного сканирования
1. Убедитесь, что URL добавлен в контекст
2. Правой кнопкой на URL → Атака → Активное сканирование
3. Настройте политику сканирования
4. Нажмите "Запустить активное сканирование"

# Из командной строки
zap-cli active-scan http://example.com

# Политики сканирования
Default Policy - базовые проверки
SQL Injection - проверки SQL-инъекций
XSS - проверки межсайтового скриптинга
Custom - пользовательская политика

Анализ предупреждений

# Просмотр предупреждений
1. Перейдите на вкладку "Предупреждения"
2. Фильтруйте по риску (High, Medium, Low, Informational)
3. Нажмите на предупреждение для деталей

# Из командной строки
zap-cli alerts # Список всех предупреждений
zap-cli alerts --risk High # Только высокий риск
zap-cli alerts --confidence Certain # Только подтвержденные

Примеры предупреждений

Риск Название URL Описание
High SQL Injection https://example.com/login Возможна SQL-инъекция через параметр 'username'
Medium Cross-Site Scripting (Reflected) https://example.com/search XSS через параметр 'query' без санитизации
Low Missing Anti-Clickjacking Header https://example.com Отсутствует заголовок X-Frame-Options
Info Application Error Disclosure https://example.com/error Страница ошибки раскрывает информацию о сервере

Генерация отчетов

# Генерация HTML отчета
zap-cli report -o report.html -f html

# Другие форматы отчетов
zap-cli report -o report.xml -f xml
zap-cli report -o report.json -f json
zap-cli report -o report.md -f md

# Из GUI
1. Файл → Экспорт отчета
2. Выберите формат (HTML, XML, JSON и т.д.)
3. Укажите имя файла и сохраните
