Безопасность в Node.js

Node.js предоставляет множество возможностей для создания безопасных приложений. Вот ключевые аспекты безопасности:

Базовый безопасный сервер
const express = require('express'); const helmet = require('helmet'); const rateLimit = require('express-rate-limit'); const app = express(); // Базовые настройки безопасности app.use(helmet()); app.use(express.json({ limit: '10kb' })); // Лимит запросов const limiter = rateLimit({ windowMs: 15 * 60 * 1000, // 15 минут max: 100 // лимит каждого IP }); app.use(limiter); // Запуск сервера app.listen(3000, () => { console.log('Сервер запущен на порту 3000'); });

Основы безопасного сервера

Этот код демонстрирует базовые меры безопасности для Node.js приложения:

Используемые пакеты:
  • express - веб-фреймворк
  • helmet - защита HTTP-заголовков
  • express-rate-limit - ограничение частоты запросов
Меры безопасности:
  • Helmet - устанавливает безопасные HTTP-заголовки
  • Лимит тела запроса - защита от переполнения
  • Ограничение запросов - защита от brute-force атак
  • HTTPS - рекомендуется в production

Ключевые пакеты безопасности:

Как защитить Node.js приложение

Рассмотрим основные методы защиты Node.js приложений от распространенных уязвимостей.

Аутентификация с JWT
const jwt = require('jsonwebtoken'); const bcrypt = require('bcrypt'); // Хеширование пароля const saltRounds = 10; const hashPassword = async (password) => { return await bcrypt.hash(password, saltRounds); }; // Создание JWT токена const createToken = (user) => { return jwt.sign( { userId: user.id }, process.env.JWT_SECRET, { expiresIn: '1h' } ); }; // Проверка пароля const comparePassword = async (password, hash) => { return await bcrypt.compare(password, hash); }; // Middleware проверки токена const authMiddleware = (req, res, next) => { const token = req.headers.authorization?.split(' ')[1]; if (!token) return res.status(401).json({ error: 'No token provided' }); jwt.verify(token, process.env.JWT_SECRET, (err, decoded) => { if (err) return res.status(403).json({ error: 'Invalid token' }); req.userId = decoded.userId; next(); }); };

Защита данных

Шифрование данных
const crypto = require('crypto'); // Шифрование const encrypt = (text) => { const iv = crypto.randomBytes(16); const cipher = crypto.createCipheriv( 'aes-256-cbc', Buffer.from(process.env.ENCRYPTION_KEY), iv ); let encrypted = cipher.update(text); encrypted = Buffer.concat([encrypted, cipher.final()]); return iv.toString('hex') + ':' + encrypted.toString('hex'); }; // Дешифрование const decrypt = (text) => { const [ivHex, encryptedHex] = text.split(':'); const iv = Buffer.from(ivHex, 'hex'); const encrypted = Buffer.from(encryptedHex, 'hex'); const decipher = crypto.createDecipheriv( 'aes-256-cbc', Buffer.from(process.env.ENCRYPTION_KEY), iv ); let decrypted = decipher.update(encrypted); decrypted = Buffer.concat([decrypted, decipher.final()]); return decrypted.toString(); };

Шифрование конфиденциальных данных

Реализация шифрования данных перед сохранением в базу данных:

Особенности:
  • Алгоритм AES-256 - надежное шифрование
  • IV (Initialization Vector) - уникальный для каждого шифрования
  • Ключ шифрования - хранится в переменных окружения
  • Гибкость - можно шифровать отдельные поля
